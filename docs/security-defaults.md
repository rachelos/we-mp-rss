# 安全默认配置

自定义 RSS 模板和 Web Git 管理默认关闭，即使旧 config.yaml 没有新配置也保持关闭。
普通 `/feed/all.json`、RSS/Atom/JSON 订阅不需要启用这两项。

```yaml
safe:
  enable_custom_rss_template: false
  enable_web_updater: false
```

`/rss/{feed_id}` 请求一旦携带 `template` 参数（包括空字符串），会在读取缓存或访问数据库前检查权限。
整个 `/api/v1/wx/github` 路由组（状态、历史、分支、更新、回滚）也受保护。
关闭时返回 403；启用后需要有效的管理员 Bearer token 或管理员 AK/SK，普通用户和级联节点不能使用。

仅当管理员完全信任模板及其来源时，才可显式设置 `ENABLE_CUSTOM_RSS_TEMPLATE=True`。
模板引擎不是安全沙箱，此修改不宣称修复引擎本身，不应向不可信用户开放表达式求值能力。
通常应使用内置格式；升级与回滚使用本地 Git。需要 Web Git 管理时可设置 `ENABLE_WEB_UPDATER=True`。
启用任一功能也不会取消管理员认证。修改后需重启后端；环境变量只能覆盖示例文件中的占位符，
已有配置请在 `safe` 下加入对应字段，或者保持缺省关闭。

示例 Compose 发布端口仅绑定宿主机 127.0.0.1；容器之间仍使用服务名通信。
内置 Redis 的示例监听地址也改为 127.0.0.1。独立 Redis 容器不受此监听设置影响。
需要跨主机使用时，应自行配置认证、网络隔离和受控的入口，不直接暴露未认证 Redis。
启动时不再输出全部环境变量，以免将凭据记录到日志中。

关联背景：Issue #485。以上是代码和部署默认值的加固，不代表确认了该事件的入侵入口或镜像来源。
